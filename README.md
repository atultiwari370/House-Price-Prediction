# House Price Prediction

## Project Overview
This project predicts house prices using Machine Learning (Linear Regression).

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Files
- house_price_prediction.ipynb
- house_price_model.pkl

## Model
- Linear Regression

## Results
- Trained and evaluated using California Housing Dataset.
- Model saved as house_price_model.pkl.
